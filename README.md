## 📚💻 Trabalho Acadêmico
Trabalho desenvolvido para fins acadêmicos🤓

## ⚙ Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- SQL
- Figma

## 💻 Projeto

Simulação de um sistema da academia "Steel Academy". O projeto é composto por um menu(tela principal) que possui as funcionalidades de cadastrar clientes, consultar dados de clientes já cadastrados através do cpf, 
cadastrar uma nova avaliação física do cliente, consultar os planos/pacotes atuais e consultar a parte financeira da academia.
